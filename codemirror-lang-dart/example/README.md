# CodeMirror Dart Example

This is a minimal example of how to use `codemirror-lang-dart` with CodeMirror 6.

## Running the example

1. Make sure the main package is built:
   ```bash
   cd ..
   npm install
   npm run build
   ```

2. Install dependencies for the example:
   ```bash
   cd example
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser to the URL shown (usually http://localhost:5173).
